# CandidateSearchUI

Angular frontend for Sulabha. Talks to the API at `http://localhost:8000`.

```
npm install
npm start      # http://localhost:4200
npx ng build
```

Pages: **Search** (results explain how each candidate matched, the filters as ✓ / ✗ / ?, and the full
record shows the candidate's search profile), **Upload Resume** (extract, review AI-suggested form, save),
**Admin** (clear or recreate the tables).
